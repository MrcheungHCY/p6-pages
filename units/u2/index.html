Sentence structures · 句式

Colour key: subject · -ing chunk · structure word · verb · object / adj

1 · ought to / should + V

someone ought to / should V
例子 · ought to
We ought to do housework every day.
例子 · should
Students should be punctual for school.
例子 · should
You should exercise regularly to stay healthy.

2 · -ing as subject + verb + …

V-ing … → verb …
例子 · -ing subject
Doing housework helps the family.
例子 · -ing subject
Getting up early makes us more energetic.
例子 · -ing subject
Sharing snacks shows that we are generous.

3 · need to be + adjective

someone need(s) to be adjective
例子 · responsible
Class monitors need to be responsible.
例子 · patient
We need to be patient when we wait in a queue.
例子 · careful
Clumsy friends need to be more careful with cups.

Notes · 筆記

  • Good habits: punctual, regular exercise, housework, responsible.
  • Gerund as subject: Doing housework helps… — see Sentence structures.
  • need to be + adjective (careful / responsible / punctual).
  • ought to / should + V for daily advice.
