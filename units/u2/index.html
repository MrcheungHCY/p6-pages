Sentence structures · 句式

Colour key: subject · -ing chunk · structure word · verb · object / adj

1 · ought to / should + base verb

Advice about habits. should + base verb (no to). ought to + base verb (one to only).

someone ought to / should V
例子 · ought to
We ought to do housework every day.
例子 · should
Students should be punctual for school.
例子 · should
You should exercise regularly to stay healthy.
Trap · form
✗ We should to make our beds. · We ought do housework.
✓ We should make our beds. · We ought to do housework.

2 · -ing as subject + singular verb

The -ing chunk is one activity, so the verb is singular: helps, is, makes. Washing the dishes is helpful — not “are”, even though dishes is plural.

V-ing … → verb …
例子 · -ing subject
Doing housework helps the family.
例子 · -ing subject
Getting up early makes us more energetic.
例子 · -ing subject
Sharing snacks shows that we are generous.
Trap · singular verb
✗ Doing housework help the family.
✓ Doing housework helps the family.

3 · need to be + adjective

After be, use an adjective (patient, careful, responsible), not an adverb and not a verb. He / she / it → needs.

someone need(s) to be adjective
例子 · responsible
Class monitors need to be responsible.
例子 · patient
We need to be patient when we wait in a queue.
例子 · careful
Clumsy friends need to be more careful with cups.
Trap · adjective, and needs
✗ She need to be patiently.
✓ She needs to be patient.

Notes · 筆記

Good habits, housework, and character adjectives. Three patterns: ought to / should, -ing as subject, and need to be + adjective.

呢個 unit 講好習慣、家務，同埋性格形容詞。句式係 ought to / should、-ing 做主語，同 need to be + 形容詞。

Words for this unit

  • Housework: make the bed 整床 · wash the dishes 洗碗 · sweep the floor 掃地 · take out the rubbish 倒垃圾
  • Adjectives: punctual 準時 · patient 有耐性 · responsible 有責任心 · generous 大方 · polite 有禮
  • careful 小心 · careless 唔小心 · clumsy 笨手笨腳 · healthy 健康 · regularly 定時

ought to / should

We ought to do housework · Students should be punctual
ought to
We ought to do housework every day.
should
Students should be punctual for school.
should
You should exercise regularly to stay healthy.

-ing as the subject

Doing housework is one thing, so the verb is singular. -ing 片語當一件事，動詞用單數。

helps
Doing housework helps the family.
makes
Getting up early makes us more energetic.
is
Washing the dishes is helpful. (not “are”)

need to be + adjective

This is not the same as need to + verb. Compare: We need to wash the dishes. We need to be careful.

responsible
Class monitors need to be responsible.
patient
We need to be patient when we wait in a queue.
needs
She needs to be careful with cups.
