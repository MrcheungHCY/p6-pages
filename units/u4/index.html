🌍 Save the Earth

Sentence structures: unless + clause · … so that + clause (purpose)

⬇ Notes ⬇ 重點 ⬇ Grammar ⬇ Comprehension Jump to 句式 隱藏陷阱 Tense practice ↗

Sentence structures · 句式

Colour key: subject · unless / so that · verb · object / result

1 · unless + present clause (= if not)

unless means if not. The unless-clause uses the present, not will. Don’t add another not — the meaning flips. unless 即係 if not。唔好寫 unless … not，亦唔好寫 unless … will。

… will / can … unless … …
例子 · unless
The beach will stay dirty unless we pick up the rubbish.
例子 · unless
Plants cannot grow well unless we save water.
例子 · unless
We will use too many plastic bags unless we bring our own.
例子 · unless
The air will stay dirty unless we reduce air pollution.
Same meaning · if not
The beach will stay dirty if we do not pick up the rubbish.

2 · … so that + clause (purpose)

so that answers “why / for what purpose”. After it, use a subject + can or will. It is not the same as so (result) or so … that (so dirty that…).

… do something so that … can / will …
例子 · so that
We turn off the lights so that we can save electricity.
例子 · so that
Our class makes a donation so that the park can plant more trees.
例子 · so that
We separate paper and plastic so that workers can recycle them.
例子 · so that
We bring our own bottles so that we can use less plastic.

Notes · 筆記

Save the Earth: talk about pollution precisely, then use unless (if not) and so that (purpose).

呢個 unit 講環保同污染。unless 即係 if not。so that 講目的，即係「做咗想得到咩」。

Eco words — use the precise one

  • air pollution 空氣污染 · water pollution 水污染 · noise pollution 噪音污染
  • rubbish 垃圾 · plastic 塑膠 · recycle 循環再造 · reuse 再用 · reduce 減少
  • save electricity 慳電 · save water 慳水 · donation 捐款 · environment 環境
pollution
✗ a pollution · save the pollution
✓ air pollution is a serious problem. We reduce air pollution.
electricity / save
✗ save electric · safe water (when you mean 慳水)
✓ save electricity · save water
save = 慳 / not waste. safe = not dangerous.
donate
✗ We donation money.
✓ We make a donation. / We donate money.

unless = if not

The beach will stay dirty unless we pick up the rubbish

Same meaning: The beach will stay dirty if we do not pick up the rubbish.

water
Plants cannot grow well unless we save water.
bags
We will use too many plastic bags unless we bring our own.
air
The air will stay dirty unless we reduce air pollution.

so that = purpose

purpose
We turn off the lights so that we can save electricity.
purpose
We separate paper and plastic so that workers can recycle them.
result · so, not so that
The sea is full of plastic, so turtles get hurt.
so + adj + that
The air is so dirty that we cannot see the hills.

so that 要有主語，後面多數 can / will。so 單獨一個係結果。so dirty that 係「咁…以致」。

Hidden traps & tricks

隱藏陷阱／小技巧

unless = if not
✓ dirty unless we pick up the rubbish
✓ dirty if we do not pick it up
no second not
✗ unless we do not pick up the rubbish
That means the opposite: the beach gets dirty if we DO pick it up. ✓ unless we pick up the rubbish
no will after unless
✗ unless we will bring our bags
✓ unless we bring our own bags
so that needs a subject
✗ so that save the Earth
✓ so that we can save electricity
purpose, not result
Result: The sea is full of plastic, so turtles get hurt.
Purpose: We pick up plastic so that turtles can stay safe.
Degree: The air is so dirty that we cannot see the hills.
word precision
✗ save electric · a pollution
✓ save electricity · air pollution

重點

  • unless = if not. Present tense. No second not. No will.
  • so that = purpose. Subject + can / will. Not the same as so (result).
  • Say air pollution and save electricity. Not “a pollution” or “save electric”.
