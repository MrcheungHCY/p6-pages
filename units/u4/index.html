Sentence structures · 句式

Colour key: subject · unless / so that · verb · object / result

1 · unless + clause (= if not)

… will / can … unless … …
例子 · unless
The beach will stay dirty unless we pick up the rubbish.
例子 · unless
Plants cannot grow well unless we save water.
例子 · unless
We will use too many bags unless we bring our own.
例子 · unless
Air will stay smoky unless factories cut pollution.

2 · … so that + clause (purpose)

… do something so that … can / will …
例子 · so that
We turn off lights so that we can save electricity.
例子 · so that
Class 6D makes a donation so that the park can buy new trees.
例子 · so that
Teachers encourage us so that we keep the classroom clean.
例子 · so that
We reuse bottles so that less plastic goes into the sea.

Notes · 筆記

  • Theme: Save the Earth — pollution types & eco-friendly actions.
  • Target structures: unless… ; … so that… — see Sentence structures.
  • Use classroom examples about recycling, saving water/electricity, and helping parks.
