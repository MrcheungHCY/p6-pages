# P.6 Tenses Practice

Calm self-study worksheet for P.6 English tenses. Easy (multiple choice) or Hard (type the full answer). 100 passages, 10 blanks each. No login. Works offline if you open `index.html` in a browser.

Write the full form (for example `will bring`, `has found`, `did not see`). Do not use contractions. Check answers, then try another passage, or export the current one as Word.
