P.6 Grammar — "used to … but …" classroom activity
HCY English · Lesson Manager

HOW TO OPEN
-----------
Double-click index.html (works offline via file://).
No install or build step. Mac or Windows browser is fine
(Chrome / Safari / Edge / Firefox).

PASSWORD (Chapter 1 → Chapter 2)
--------------------------------
Case-insensitive secret word: but
Enter it in the "Secret Word Required" modal after
"Proceed to Chapter 2". Correct answer shows fireworks
and "Unlocked!", then opens Chapter 2.

CHAPTERS
--------
Chapter 1 — Red or Blue Portal
  Tap Red or Blue to fill the screen; tap anywhere to reset.
  Bottom-right: Proceed to Chapter 2 (password gated).

Chapter 2 — Story Illustrator
  Write a "used to … but …" sentence → Generate Magic Image.
  Shows a before|after picture with your sentence as caption.
  "Draw another change" resets; "Back to Chapter 1" returns.

IMAGE MODE (default: offline placeholder)
-----------------------------------------
By default there is NO API key. The class works with zero
network: Generate Magic Image draws a polished local
Past | Present SVG placeholder and puts the student sentence
underneath.

Optional API (later):
  1) Edit CONFIG.apiKey at the top of the script in index.html, OR
  2) Open with a query string: index.html?key=YOUR_KEY
  Then the page tries Imagen 4 (imagen-4.0-generate-001) via
  generativelanguage.googleapis.com. On any failure it falls
  back to the offline placeholder (soft note may appear).
  Do NOT hardcode or share a real API key in this folder.
