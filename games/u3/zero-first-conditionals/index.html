ZERO

If + present, present

Facts & habits 事實／習慣
If it rains, the ground gets wet.
If they play, they get muddy.

he/she/it → +s / +es
I/you/we/they → base (no +s)

FIRST

If + present, will + base

Possible future 可能將來
If it rains, we will stay home.
If she studies, she will pass.

If-clause: present (+s for he/she/it)
will-clause: always base (no +s)

⚠️ Do NOT use will in the if-clause.
❌ If it will rain… → ✅ If it rains…
watch → watches (not watchs) · cry → cries · go → goes
