HCY English · P.6 · Weather & Disasters — Vocab Game
====================================================

HOW TO OPEN (offline, no internet needed)
-----------------------------------------
Mac:
  1. Open Finder and go to this folder.
  2. Double-click index.html
  3. It opens in Safari / Chrome / Edge.

Windows:
  1. Open File Explorer and go to this folder.
  2. Double-click index.html
  3. It opens in Edge / Chrome / Firefox.

If it opens as text: right-click index.html → Open with → your browser.

WHAT'S INSIDE
-------------
A) Picture pick — look at a scene, tap the matching word (all 8 words).
B) Word match — match each word to its short meaning (tap or drag).
C) Timed letter scramble — unscramble letters against a 60-second timer.
Play all — runs A → B → C in order.

Correct answers: soft cheer sound + confetti.
Wrong answers: no fireworks.

WORDS
-----
heavy rain, a drought, thunder and lightning, a typhoon,
a flood, a landslide, an earthquake, a snowstorm

Tips for class: use a projector or tablets; big touch buttons work well.
No API keys. Single file — copy the whole folder if you share it.
